#### KataGo Installation Recommanded

|                    |         
|:-------------------|
|Many functions, especially analysis related, of this app rely on Go Engine's performance. To do so, the app has equipped GNU Go and Leela Zero as default, and KataGo can be interfaced as described in the manual. Among the available Go Engines, KataGo is considered the best in speed and accuracy, and recommanded to run with the app.|
